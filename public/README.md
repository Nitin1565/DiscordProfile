# Public Assets Folder

You can drop your custom media files right here in this folder:

- **Custom Background Video**: Drop `background.mp4` here, then in `config.js` set `videoUrl: "/background.mp4"`
- **Custom Music**: Drop `music.mp3` here, then in `config.js` set `audioUrl: "/music.mp3"`

Any file placed in this `public` directory is served directly at the root URL (e.g., `/background.mp4`, `/music.mp3`) by Vite!
